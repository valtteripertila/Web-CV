Sivuston rakenne

Tällä sivulla kuvataan sivuston muodostaminen ja julkaisu.

Yleiskuva

Tämä kaksikielinen ansioluettelo kirjoitetaan rakenteisina JSON-tiedostoina ja muodostetaan staattiseksi HTML-sivustoksi Pythonin vakiokirjastolla.

Arkkitehtuuri

content/*.json
  -> build.py
  -> site/
  -> GitHub main
  -> Cloudflare Pages

Automaattiset tarkistukset

  • Sisällön muodostustarkistus läpäisee.
  • Yksikkötestit läpäisevät.
  • Sisäiset linkit, kohdat ja resurssit löytyvät.
  • Englannin- ja suomenkieliset sivut ja käännökset pysyvät rinnakkain.
  • HTML-tunnisteet, tunnisteet, pääotsikot ja kielimerkinnät ovat kelvollisia.
  • Jokaisella sivulla on yksi yläpalkki ja toimivat kieli- ja valikkolinkit.
  • HTML ja CSS eivät lataa ulkoisia resursseja.
  • Molempien teemojen värit läpäisevät mitatut kontrastirajat.
  • Yksityisiä yhteystietoja ei ole lisätty.
  • Julkaistut sivutiedostot vastaavat väliaikaista uutta koostetta.
