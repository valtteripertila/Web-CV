Overview

This bilingual CV is authored as structured JSON and rendered to static HTML by a Python standard-library build script.

Architecture

content/*.json
  -> build.py
  -> site/
  -> GitHub main
  -> Cloudflare Pages

Content model

FileWhat it holds
changelog.jsonBilingual entries based on repository history.
en.jsonEnglish CV content and interface strings.
experience.jsonBilingual work-history entries.
fi.jsonFinnish CV content and interface strings.
now.jsonOptional current-focus entries.
projects.jsonBilingual project entries.
quality.jsonOptional manually measured Lighthouse results.
shared.jsonName, contact links, repository and site domain.
site_info.jsonOverview prose and optional AI note.

Automated checks

  • Build content validation passes.
  • Unit tests pass.
  • Internal links, fragments and assets resolve.
  • English and Finnish pages and translations stay in parity.
  • HTML tags, ids, headings and language attributes are valid.
  • HTML and CSS load no external resources.
  • Both theme palettes pass measured contrast thresholds.
  • No private contact details are included.
  • Committed site files match a fresh temporary build.
